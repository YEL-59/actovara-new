# 📁 EasyTemplate v2.0: Universal Full-Stack & Figma Architecture Guide (A to Z)

> **Philosophy**: Combines the best of `ai_framwork` (`.agents/skills/` playbooks, `docs/` technical blueprints, modular domain backend, 11 6-state UI primitives) with `EasyTemplate`'s Zero-Docker speed, **Universal Any-Backend Engine**, **Figma-to-Fullstack automation**, **PDF & Telegram Chat Reader**, and **Persistent Session Memory (`planning/MEMORY.md`)**.

## 2. How EasyTemplate v2.0 Unifies `ai_framwork` + Universal Flexibility

| Feature | `ai_framwork` (Avengerse) | EasyTemplate v1.0 | **EasyTemplate v2.0 (Unified Best-of-Both)** |
|---|---|---|---|
| **Backend Support** | Locked to NestJS + Prisma + Postgres | Locked to Express + Mongoose | **Universal Any-Backend** (`EXPRESS_MONGOOSE`, `EXPRESS_PRISMA_POSTGRES`, `NESTJS_PRISMA_POSTGRES`, `FASTAPI_PYTHON`, `CUSTOM_ANY`) |
| **Figma Support** | Static doc only | Screenshots only | **Full Figma-to-Fullstack Engine** (`inputs/figma/`, Figma MCP live inspection, auto-inferred DB ERD & APIs) |
| **Client Input Reader** | Manual `README.md` | Manual copy-paste | **Automated Input Parser (`npm run inputs`)** reading PDFs, Telegram `messages.html`/`.txt`/`.json`, Figma URLs, and Screenshots |
| **Agent Skills & Docs** | `.agents/skills/` + `docs/` | `PRD_AND_PLAN.md` only | **Both!** 9 `.agents/skills/` playbooks + modular `docs/` (`01`-`13` + `context-map.md`) + `PRD_AND_PLAN.md` |
| **UI Primitives** | 11 primitives (`src/components/ui/`) | 2 primitives (`Button`, `Card`) | **All 11 6-State UI Primitives** (`Alert`, `Badge`, `Button`, `Card`, `Dialog`, `EmptyState`, `Input`, `Skeleton`, `SpecTable`, `Tabs`, `Textarea`) |
| **Session Memory** | `updateplanning.md` only | `MEMORY.md` + `PROJECT_STATUS.md` | **Full Persistent Memory Bank (`MEMORY.md`)** + Bilingual (`EN`/`BN`) CLI Settings |
